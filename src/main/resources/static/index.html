使用说明

1. 点击「生成模拟轨迹」创建测试数据

2. 点击「刷新」加载轨迹列表

3. 点击某条轨迹在地图上展示

4. 使用播放控件回放轨迹动画

5. 点击地图任意位置可上报坐标或打卡

6. 「定位打卡」区域可记录并查看打卡点

7. WebSocket 实时推送需后端运行中

提示：生产环境请替换地图源为自部署的 TileServer-GL
